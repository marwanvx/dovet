# Dovet

A terminal coding agent for Windows, macOS and Linux that works with any model provider.

**Its promise: the agent can't hide what it did, what it cost, or what it was told.**

> **Status:** early development (milestone M0). There is nothing to install yet. The plan and the specs are in [docs/](docs/README.md).
