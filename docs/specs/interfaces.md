These are the **normative** type contracts. Implementations use zod schemas that infer exactly these types (`schema` module). Any change here needs an ADR. Names are final unless an ADR says otherwise.

## 1. Shared primitives

```ts
type Ulid = string;               // 26-char ULID
type IsoTime = string;            // ISO-8601 UTC, ms precision
type AbsPath = string;            // canonical absolute path (platform-native separators)
type BlobRef = { store: "blob" | "git"; id: string }; // sha256 hex, or git object id
type Protocol = "anthropic-messages" | "openai-responses" | "google-interactions" | "openai-chat";
type PermissionMode = "default" | "acceptEdits" | "plan" | "dontAsk" | "bypassPermissions" | "auto";   // "manual" accepted as an input alias of "default" (permissions §2)
type Usd = number;                // dollars, float; display rounds to cents (or 4 dp below $0.01)
```

## 2. Conversation parts (Dovet's own format; what the event log stores)

```ts
type Part =
  | { kind: "text"; text: string; phase?: "commentary" | "final_answer"; replay?: ReplayData }
  | { kind: "image"; blob: BlobRef; mediaType: "image/png" | "image/jpeg" | "image/gif" | "image/webp" }
  | { kind: "document"; blob: BlobRef; mediaType: "application/pdf"; title?: string }
  | { kind: "reasoning"; summary: string | null; replay?: ReplayData }
  | { kind: "tool_call"; id: string; name: string; inputJson: string; replay?: ReplayData }
  | { kind: "tool_result"; callId: string; isError: boolean; content: Array<TextPart | ImagePart | DocumentPart> }  // models without document support in tool results (capability pdfInToolResult) get the PDF as an extra user part
  | { kind: "instruction"; text: string; reason: InstructionReason };

/** One per fixed text in prompts/instructions.md (the key names there), plus queued user messages. */
type InstructionReason = "interrupt-note" | "continue-after-drop" | "mode-change" | "sandbox-changed"
  | "plan-approved" | "plan-not-approved" | "plan-left" | "plan-reattach" | "restore-note"
  | "instructions-updated" | "lazy-instructions" | "user-shell-output" | "silence-reminder" | "open-tasks"
  | "budget-warning" | "queued-messages";

/** Provider data a part needs to be replayed exactly: Anthropic thinking `signature` / `redacted_thinking` data,
 *  OpenAI item `id`, `encrypted_content` and `phase`, Gemini thought signatures, chat-protocol `reasoning_content`,
 *  server-tool blocks. Field names and values are the provider's own wire-format ones, never a library's internal
 *  structure, so the log doesn't depend on the AI SDK (ADR-30). Opaque to everything but the adapter. */
type ReplayData = { provider: string; protocol: Protocol; modelId: string; fields: Record<string, JsonValue> };
type JsonValue = string | number | boolean | null | JsonValue[] | { [key: string]: JsonValue };
```
Assistant output is stored as `Part[]` inside `model.response` (`StoredResponse`, [interfaces §3](interfaces.md), [event-log](event-log.md)); these parts plus their `replay` data are the replay source. The adapter converts them to and from the AI SDK's message format; nothing else sees that format.

```ts
}

interface Platform {                        // in `platform`; fakeable in tests
  os: "linux" | "darwin" | "win32"; arch: string;
  canonicalize(p: string, cwd: AbsPath): AbsPath;
  spawn(cmd: { argv: string[]; cwd: AbsPath; env: Record<string, string>; stdin?: "null" | string; signal: AbortSignal; group: string }): ChildHandle;
  killTree(group: string): Promise<void>;   // ProcessManager: one group per session (extensibility)
  shells(): { bash?: AbsPath; powershell?: AbsPath; gitBash?: AbsPath };
  clipboard: { readImage(): Promise<Uint8Array | null>; writeText(t: string): Promise<void> };

}
```

## 3. Provider adapter (one generic implementation over the AI SDK, ADR-30)

```ts
/** Implemented once (`ai/sdk-adapter.ts`) over AI SDK `LanguageModel` instances created from the provider package the
 *  registry names. Per-provider differences are registry data and `providerOptions`, never adapter subclasses. */
interface ProviderAdapter {
  capabilities(model: ModelInfo): Capabilities;
  /** Pure + deterministic: same inputs → identical call options (messages, tools sorted by name, providerOptions). */
  render(input: RenderInput): SdkCall;
  /** Runs `streamText` for one model step (tools without `execute`, `maxRetries: 0`, `allowSystemInMessages: true`) and maps
   *  its `fullStream` parts (text-start/-delta/-end, reasoning-*, tool-input-*, tool-call, finish-step, error, abort) to
   *  StreamEvents. A custom `fetch` records the exact request bytes and their SHA-256 into `ProviderRequest`. */
  stream(call: SdkCall, opts: { signal: AbortSignal; onRequest: (req: ProviderRequest) => void }): AsyncIterable<StreamEvent>;
  /** Lossless: the AI SDK response messages of one step → Dovet parts with replay data. `render` converts them back;
   *  the round trip must reproduce the SDK messages exactly (contract test, SPIKE-44). */
  toStored(sdkResult: unknown, ctx: { provider: string; package: string; packageVersion: string; modelId: string }): StoredResponse;
  classifyError(err: unknown): ProviderErrorInfo;   // from the SDK's APICallError (status, body, headers) and stream error parts
}

/** Optional per-provider code (providers "Provider modules"), looked up by registry record id. Every hook is optional;
 *  missing hooks use the generic behavior. Modules never see or change the transcript. */
interface ProviderModule {
  recordId: string;
  login?(signal: AbortSignal): Promise<{ secret: string; refresh?: string; expiresAt?: number }>;   // a login flow the generic api-key/oauth flows can't express (cli-config)
  listModels?(endpoint: Endpoint, signal: AbortSignal): Promise<ModelInfo[]>;   // e.g. local-server discovery
  prepareRequest?(call: SdkCall, ctx: { endpoint: Endpoint; sessionId: string }): SdkCall;   // pure: headers, providerOptions
  readUsage?(raw: RawUsage): { cachedInput?: number; cacheWrite?: number; reasoningOutput?: number };   // when usageFields paths aren't enough
  classifyError?(err: unknown): ProviderErrorInfo | undefined;           // undefined → generic classification
}

type SdkCall = { provider: string; package: string; modelId: string; messages: unknown /* AI SDK ModelMessage[] */;
  tools: unknown /* tool definitions without execute */; providerOptions: Record<string, unknown>; maxOutputTokens?: number;
  headers?: Record<string, string> };
/** What `model.response` stores, in Dovet's own format: the step's assistant parts in order, each carrying the
 *  provider's replay data — the replay source. `rawBody` is set only with `--debug` (event-log). */
type StoredResponse = { provider: string; protocol: Protocol; package: string; packageVersion: string; modelId: string;
  parts: Part[]; usage: RawUsage; finishReason: string; rawBody?: BlobRef };

interface RenderInput {
  header: EpochHeader;                      // frozen: system text, tool defs (serialized), model, thinking config
  params: { effort?: string; maxTokens: number };
  transcript: TranscriptItem[];             // user parts, stored responses, tool results, instructions — in order
  cache: { breakpoints: "auto" | "explicit"; ttl: "auto" | "5m" | "1h" };
}

type StreamEvent =
  | { type: "text.delta"; blockIndex: number; text: string }
  | { type: "reasoning.delta"; blockIndex: number; text: string }      // summaries/progress only
  | { type: "tool_call.start"; blockIndex: number; id: string; name: string }
  | { type: "tool_call.delta"; blockIndex: number; partialJson: string }
  | { type: "block.done"; blockIndex: number; kind: "text" | "reasoning" | "tool_call" }  // enables early tool execution
  | { type: "usage"; usage: RawUsage }
  | { type: "done"; stopReason: StopReason; stored: StoredResponse; requestId?: string; servedBy?: string }
  | { type: "error"; error: ProviderErrorInfo }
  /** Last event after the signal aborts. `completed` holds only the blocks that finished (text, signed thinking,
   *  complete tool calls) as stored parts; null if none ([agent-loop](agent-loop.md) Interrupts). */
  | { type: "aborted"; completed: StoredResponse | null };

type StopReason = "end_turn" | "tool_use" | "max_tokens" | "context_exceeded" | "refusal" | "pause" | "stop_sequence" | { other: string };

interface ProviderErrorInfo {
  kind: "rate_limit" | "overloaded" | "server" | "network" | "timeout" | "auth" | "billing" | "quota"
      | "invalid_request" | "not_found" | "too_large" | "refusal_policy" | "prefix_mismatch" | "unknown";
  retryable: boolean;
  retryAfterMs?: number;
  status?: number;
  requestId?: string;
  message: string;                          // provider message, secrets redacted
}
```

## 4. Tools

```ts
interface ToolDefinition<I, O = ToolOutput> {
  name: string;                             // e.g. "Read", "Bash"
  input: z.ZodType<I>;                      // strictObject
  descriptionFile: string;                  // prompts/tools/<name>.md, the same for every model (prompts/README.md)
  errorExample: I;                          // one valid call, shown in validation errors (tools §0); a test checks it parses with `input`
  parallelSafe: boolean;
  mutates: "none" | "files" | "system" | "network";
  /** What the policy engine evaluates; derived without side effects. */
  describeAction(input: I, ctx: ToolContext): ActionDescriptor;
  run(input: I, ctx: ToolContext): Promise<O>;
}

interface ToolContext {
  session: Readonly<SessionInfo>;           // id, cwd, workingDirs, mode, taint, interactive — read-only snapshot
  settings: Readonly<Settings>;             // resolved settings, frozen for the turn
  signal: AbortSignal;
  readState: ReadStateStore;
  snapshots: SnapshotService;
  emit(e: ToolProgressEvent): void;         // live tail, status
  sandbox: SandboxService;
  platform: Platform;
  /** User interaction. Rejects with `NoUserAvailable` when `session.interactive` is false. */
  interact: {
    askQuestions(q: AskUserQuestionInput, signal: AbortSignal): Promise<QuestionAnswers>;
    presentPlan(plan: { text: string; path: AbsPath }, signal: AbortSignal): Promise<PlanAnswer>;
  };
  /** Secondary model call for tools that need one (WebSearch, ADR-25). Costs are attributed to the calling tool. */
  model: { complete(req: SecondaryRequest, signal: AbortSignal): Promise<SecondaryResult> };
}

/** Tools never mutate session state. They return effects; the agent validates and applies them in order and logs them. */
type SessionEffect =
  | { kind: "set-mode"; mode: PermissionMode }            // EnterPlanMode / ExitPlanMode
  | { kind: "taint"; source: string }                     // WebFetch, WebSearch, (v0.2) MCP
  | { kind: "cwd"; path: AbsPath };                       // Bash `cd` (only inside working dirs, else ignored with a note)
// Read-state is the one exception: `ctx.readState` is a session-owned store that file tools update directly (tools §0).

/** tools §11.4. `previous` = return to the mode active before plan mode (only offered for acceptEdits/bypassPermissions). */
type PlanAnswer =
  | { approve: "previous" | "accept-edits" | "manual"; edited: boolean }
  | { keepPlanning: string }
  | { dismissed: true; reason: "esc" | "mode-changed" };

type SecondaryRequest = { purpose: "websearch"; query: string; allowedDomains?: string[]; blockedDomains?: string[] };
type SecondaryResult = { results: Array<{ title: string; url: string; snippet?: string }>; usage: RawUsage; serverToolCalls: number; requestId?: string };

type ToolOutput = {
  status: "ok" | "error" | "denied" | "interrupted" | "timeout";
  content: Array<TextPart | ImagePart | DocumentPart>;
  meta?: { exitCode?: number; durationMs?: number; offloadPath?: AbsPath; sandboxViolations?: string[]; fileChanges?: FileChange[]; effects?: SessionEffect[] };
  /** v0.2: post-processors (LSP diagnostics) may append parts here; the tool contract does not change. */
};

/** What the policy decides on (ADR-28, permissions §0b). */
type Effects = {
  writes: "workspace" | "outside" | "protected" | "none" | "unknown";   // "workspace" = covered by checkpoints
  network: "none" | "allowed-hosts" | { newHosts: string[] } | "unknown";
  sensitiveReads: AbsPath[];
  remote: Array<"push" | "publish" | "upload" | "deploy" | "destructive-mcp">;
  sandboxed: boolean;                       // a healthy sandbox enforces writes/network (else they are "unknown" for shell)
};

type ActionDescriptor = { effects: Effects } & (
  | { kind: "read"; paths: AbsPath[] }
  | { kind: "edit"; paths: AbsPath[]; preview?: { path: AbsPath; diff: string }[] }
  | { kind: "shell"; shell: "bash" | "powershell"; command: string; parsed: ParsedCommand; sandboxed: boolean; unsandboxedRetry: boolean }
  | { kind: "network"; url: string; host: string; via: "webfetch" | "websearch" }
  | { kind: "interaction" }                 // AskUserQuestion / ExitPlanMode
  | { kind: "task-list" }                   // TodoWrite: no side effects
  | { kind: "mcp"; server: string; tool: string } );   // v0.2
```

## 5. Policy engine

```ts
interface PolicyEngine {
  decide(action: ActionDescriptor, tool: string, input: unknown, ctx: PolicyContext): PolicyDecision;
  /** Rules the "don't ask again" option would save, or null if none can be expressed safely. */
  suggestRules(action: ActionDescriptor, tool: string): string[] | null;
}

type PolicyDecision =
  | { outcome: "allow"; source: DecisionSource }
  | { outcome: "deny"; source: DecisionSource; message: string }          // message goes to the model
  | { outcome: "ask"; reasons: AskReason[]; offerRemember: boolean; countdownMs?: number };

type DecisionSource = { type: "rule"; rule: string; file: string } | { type: "mode"; mode: PermissionMode }
  | { type: "builtin"; check: "read-only-command" | "working-dir-read" | "sandbox-auto-allow" | "plan-file" | "protected-path"
      | "critical-path" | "network-path" | "remote-action" | "sensitive-file" | "taint" | "force-push" } | { type: "user"; requestId: Ulid } | { type: "hook"; name: string };

/** Each reason names the boundary it protects (permissions §0b); "review-edit" is the user's Manual-mode review preference. */
type AskReason = "review-edit" | "no-matching-rule" | { askRule: string } | "protected-path" | "critical-path" | "outside-working-dirs"
  | "unsandboxed-retry" | "no-sandbox" | "network-host" | "remote-action" | "tainted" | "network-path" | "unparseable-command"
  | "sensitive-file" | "hard-linked";

type ParsedCommand = {
  ok: boolean;                              // false → unparseable
  subcommands: Array<{ argv: string[]; raw: string; wrappersStripped: string[]; redirects: Array<{ op: string; target: string }> }>;
  hasSubstitution: boolean;
  removals: Array<{ target: string; recursive: boolean; critical: boolean; why?: string }>;
  interactive: boolean;                     // needs a TTY
};
```

## 6b. Receipt (persisted in `receipt` events; included in headless JSON)


## 9. Composition root and test seams

Everything that differs between production, tests and (v0.2) subagents/ACP is passed in **once**, at `createRuntime`. Nothing reads these from globals.

```ts
interface RuntimeDeps {
  clock: { now(): number };                 // tests: fake clock
  ids: { ulid(): Ulid };                    // tests: deterministic sequence
  platform: Platform;                       // tests: fake or real per OS
  dirs: { config: AbsPath; data: AbsPath; cache: AbsPath };
  env: Readonly<Record<string, string>>;    // snapshot of process.env taken once at startup
  baseUrls?: Partial<Record<string, string>>; // tests: point providers at the fixture server
  stdio: { isTTY: boolean };
}
function createRuntime(deps: RuntimeDeps): Runtime;   // process-wide: config, catalog, secrets, blob store, GC lock
interface Runtime { openSession(opts: SessionOptions): Promise<Session>; close(): Promise<void> }
```

**State rules (CI-enforced where possible):**
- No module-level mutable state (lint: no top-level `let`; top-level `const` only for immutable values). Caches live on `Runtime` or `Session`.
- Never `process.chdir()`; never write `process.env` (lint-banned). The cwd is `Session` state; child environments are built per spawn.
- Only `cli/main.ts` touches `process.*` (argv, exit, signals, env) and calls `createRuntime`.
- Two sessions in one process must work. This is tested in M1 (two sessions in different temp projects, interleaved turns, no cross-talk), because subagents and ACP (v0.2) and parallel `bun test` files depend on it.

## 10. Public output schemas (stability boundary)

`--output json` (one object: `{ schema: "dovet.json/1", result, stopReason, incomplete, sessionId, receipt, usage, cost }`; `incomplete` is true when a headless run ended with open task-list items, [agent-loop](agent-loop.md)), `--output stream-json` (U+2028/U+2029 escaped, [event-log](event-log.md)) and (v0.2) ACP are **public contracts**, separate from the internal event log. `cli/output/` maps `AgentEvent`s to `dovet.stream/1` objects (documented in `schema/stream.schema.json`). Internal events can change with a `v` bump; the public schema changes only with a new major version (`dovet.stream/2`), and the old one is kept for one minor release.
