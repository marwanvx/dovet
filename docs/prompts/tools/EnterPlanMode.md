Switches to plan mode so you can investigate and agree on an approach with the user before changing anything. Use it for large or risky changes, when several approaches are plausible and the choice matters, when the request is unclear enough that you'd otherwise guess, or when the user asks for a plan. Don't use it for small, clear tasks, or for questions and research that need no changes.

In plan mode you can read files and run commands that only inspect; the one file you can write is the plan file. When the plan is ready, write it there and present it with ExitPlanMode.
