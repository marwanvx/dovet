# M3 tasks — Usable alpha

Milestone goal and exit evidence: [roadmap "M3"](../roadmap.md). How tasks are run: [build loop](../../workflow/build-loop.md).
Agents change only the `Status:` lines (`todo` · `in-progress` · `blocked` · `done (#PR)`). Every task follows the test-quality rules ([testing "Test-quality rules"](../../specs/testing.md)): tests first, seen failing, then the code.

> **For the plan check when M3's first task starts (build loop step 4):** `runHeadless` in `src/cli/headless-run.ts` is one function of about 1,800 lines that holds the wiring of every M2 feature (sandbox, budgets, web search, images, checkpoints, compaction). The interactive session needs the same wiring. No task here moves it to a place both can call, and the headless tests would not notice a feature wired in one path and missing in the other. Add that task before M3-01, or confirm that `Session` already carries the wiring.
