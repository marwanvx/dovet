# Open Questions & Spikes

Every unverified assumption in the specs is listed here, and each one is cited (`[SPIKE-n]`) at the spec section it affects. Each spec's "Before you build" box repeats its spikes with their fallbacks, so an agent sees them without opening this file. A **spike** is a small, time-boxed experiment (usually ≤ 1 day) that produces a written answer and, if needed, a spec/ADR change. Features marked with a spike must not be built until it's resolved.

Last updated: 2026-10-12.
